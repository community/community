# Security Policy

## Supported Versions

Only the latest release and active `main` branch receive security updates.

| Version | Supported |
| ------- | --------- |
| Latest (`main`) | ✅ Yes |
| Older releases | ❌ No |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report them privately using one of the following methods:
* **GitHub Private Vulnerability Reporting:** Go to the **Security** tab of this repository and click **Report a vulnerability**.
* **Email:** Send details to `[security@yourdomain.com]` with a clear description, steps to reproduce, and potential impact.

### What to Expect
* **Acknowledgment:** You will receive a response confirming receipt within **48 hours**.
* **Updates:** We will keep you informed as we investigate, validate, and prepare a fix.
* **Disclosure:** Once a patch is released, we will coordinate public disclosure and credit you (unless you prefer to remain anonymous).
